# Design spec: Asendus look

Built with the design-library skill. Tokens live in `web/src/index.css`.

## Decisions

- **Base:** light. It is a daily work tool. The base is tinted blue-grey (`#eaf0f7`), not white; cards stay white.
- **Palette:** school blue, tinted.
  - primary `#59adf6` / dark `#2a85d4` / soft `#a8d5fb`
  - secondary (navy ink) `#1e3a8a` / dark `#14285f` / soft `#6585df`
  - highlight `#f6de5c`; hot gradient is highlight → primary-soft
  - text `#1f2a44`, muted `#5b6478`, border `#cfdbe9`, surface-raised `#dde6f1`
  - The `casual-*` categorical set stays for status colours (free, ask first, duties).
- **Hero:** shader background. `contours.frag` on a navy base fills the landing page; one screen with the decrypting headline, one hot word ("olemas.") and the Google sign-in.
- **App background:** `contours-light.frag`, a slower variant that mixes faint ink lines into the light base, fixed behind the logged-in pages. Hidden in print.
- **Type:** Catamaran for UI and display (800 for headings).
- **Icon:** a swap-arrows mark on a pressable sky tile (`web/public/favicon.svg`), used as favicon, nav logo and landing logo.

## Signatures in use

1. Pressable buttons: `RealButton` everywhere.
2. Decrypt text: the landing headline, with Estonian letters and period numbers as glyphs.
3. Sliding selection: the nav (`SlidingNav`), a pill that slides under the current page.
4. Colour with intent: one hot word on the landing page; `casual-*` colours code candidate status.

## Known gaps

- White text on primary sky blue is below 4.5:1 contrast. The existing `sky` RealButton has this; unchanged for now.
